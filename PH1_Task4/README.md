# Task 4 — Data Validation Checks

Validates the product catalog data used by the visual search system: null checks, data type checks, range checks, and referential integrity checks, per the task brief.

## What's here

```
PH1_Task4/
├── README.md
├── requirements.txt
├── validate.py                      ← main validation script
├── data/
│   ├── raw/
│   │   └── product_catalog_export.csv   ← same sample source used in Task 3, deliberately messy
│   └── lookup/
│       ├── valid_categories.csv          ← reference table for category referential integrity
│       └── valid_brands.csv              ← reference table for brand referential integrity
├── docs/
│   └── validation_logic.md          ← explains every rule and the assumptions behind it
└── reports/
    └── validation_report.md         ← output of the actual run — real numbers, not illustrative
```

## Run it

```bash
pip install -r requirements.txt
python validate.py
```

Prints a one-line summary to the console and (re)writes the full report to `reports/validation_report.md`.

## Deliverables mapping

| Deliverable | Location |
|---|---|
| Python script implementing validation checks | `validate.py` |
| Report summarizing validation results | `reports/validation_report.md` (generated by running the script; committed here as the actual output of a real run) |
| Documentation of validation logic and assumptions | `docs/validation_logic.md` |

## Result of the run committed here

11 rows checked, 13 violations found across 6 rows (5 rows fully clean). Full breakdown by check type and every individual violation is in [`reports/validation_report.md`](reports/validation_report.md); the reasoning behind each rule is in [`docs/validation_logic.md`](docs/validation_logic.md).
