# Reference / External Datasets

This folder is a placeholder for external reference datasets mentioned in the inventory report (`../docs/data_sources_inventory_report.md`, Section 3). Raw dataset files are not committed here (too large for GitHub) — download links below.

| Dataset | Purpose | Link |
|---|---|---|
| Instacart Market Basket Analysis | Reference for user purchase-behavior modeling | https://www.kaggle.com/datasets/irfanasrullah/instacart-market-basket-analysis |
| Amazon Berkeley Objects (ABO) | Pretraining reference for product image similarity | https://amazon-berkeley-objects.s3.amazonaws.com/index.html |
| DeepFashion | Pretraining reference for fashion-category visual search | https://mmlab.ie.cuhk.edu.hk/projects/DeepFashion.html |

If you download any of these for local experimentation, keep them out of version control (see `.gitignore`) and note the local path + any subset you sampled here.
